# Sports Field Reservation System

A web-based sports field reservation system developed for the **Database Systems course at UNNES (2025)**. This project addresses manual booking challenges—such as long queues, limited visibility, and double bookings—by digitizing the entire reservation workflow.

## 🚀 Key Features

* **User Dashboard:** Browse available sports fields, check real-time schedules, and manage personal bookings.
* **Admin Panel:** Complete management of field data, user accounts, schedules, and reservation statuses.
* **Real-Time Monitoring:** Instant status updates to prevent booking conflicts.
* **Secure Authentication:** Role-based access control with fast, secure authentication.
* **Optimized Performance:** Sub-2-second loading times and structured relational data management.

## 💻 Tech Stack

* **Language/Framework:** PHP
* **Database:** MySQL (15+ structured database tables)
* **Architecture:** Relational Database Management System with custom web interfaces

## 📊 Project Metrics

* **Pages:** 15+ functional pages
* **Database:** 15+ structured tables
* **Codebase:** 2,000+ lines of code
* **Efficiency Gain:** Reduced reservation time from 30 minutes down to 5 minutes while completely eliminating double-booking errors.
