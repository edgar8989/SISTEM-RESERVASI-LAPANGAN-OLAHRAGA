-----------------------------------------------------------------------------------------------
Alur User
1. User pilih gor (unnes atau undip)
2. User pilih lapangan (Futsal, Voly, basket, badminton)
3. User pilih jadwal
4. User pilih fasilitas
5. User isi form biodata
6. User bayar
7. sukses



Alur Admin
1. klik reservasi pojok kanan atas
2. Admin bisa update jam, fasilitas, status. (crud)






================================================================================
                               flowchart
================================================================================

    +-------------+         +-----------------+          +----------------+
    |     GOR     |         |    LAPANGAN     |          |   FASILITAS    |
    +-------------+    1:N  +-----------------+          +----------------+
    | id_gor (PK) |-------->| id_lapangan (PK)|          |id_fasilitas(PK)|
    | nama_gor    |         | id_gor (FK)     |          |nama_fasilitas  |
    | kota        |         | nama_lapangan   |          +-------+--------+
    +-------------+         | harga_per_jam   |                  ^
                            +--------+--------+                  |
                                     |                           |
                                     | 1:N                       |
                                     v                           |
                            +-----------------+        (Pivot Lapangan)
                            |     JADWAL      |        +--------------------+
                            +-----------------+        | LAPANGAN_FASILITAS |
                            | id_jadwal (PK)  |        +--------------------+
                            | id_lapangan (FK)|------->| id_lapangan (FK)   |
                            | tanggal, jam    |        | id_fasilitas (FK)  |--------+
                            | status          |        +--------------------+        |
                            +--------+--------+                                      |
                                     |                                               |
                                     | 1:N (Satu jadwal dipilih satu reservasi)      |
                                     v                                               |
================================================================================     |
                                  TRANSAKSI                                          |
================================================================================     |
                                     |                                               |
    +-------------+         +--------+--------+          +-------------------+       |
    |    ADMIN    |    1:N  |    RESERVASI    | 1:N      | RESERVASI_FASILITAS|      |
    +-------------+         +-----------------+          +-------------------+       |
    | id_admin(PK)|-------->| id_reservasi(PK)|<---------| id_reservasi (FK) |       |
    | nama, email |         | id_jadwal (FK)  |          | id_fasilitas (FK) |<------+
    +-------------+         | id_pelanggan(FK)|          +-------------------+   (Sama-sama
                            | id_admin (FK)   |                                   ambil dari
                            | tgl_reservasi   |                                   Fasilitas)
                            +--------+--------+
                                     ^
                                     | 1:N
                            +--------+--------+
                            |    PELANGGAN    |
                            +-----------------+
                            | id_pelanggan(PK)|
                            | nama, email     |
                            +--------+--------+
                                     |
                                     | 1:1
                            +--------v--------+
                            |   PEMBAYARAN    |
                            +-----------------+
                            | id_pembayaran(PK|
                            | id_reservasi(FK)|
                            | total_bayar     |
                            | status          |
                            +-----------------+
